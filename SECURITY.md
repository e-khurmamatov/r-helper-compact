# Security

Security fixes target the latest release. Include the app version, Windows version and reproducible steps when reporting a vulnerability.

Use GitHub's private vulnerability reporting if it is enabled for this repository. Otherwise, open an issue requesting a private contact channel without posting exploit details or private data. Ordinary bugs belong in the bug report template.

Download builds only from this repository's Releases. Releases are currently unsigned; published SHA-256 checksums detect corrupted downloads but do not establish publisher identity.
